# Структура Kotoba

## Модули

| Файл | Ответственность |
| --- | --- |
| `manga_translator.py` | Обработка страницы и главы, порядок этапов, отмена, статистика и CLI |
| `settings.py` | Проверяемые настройки задания, нормализация адреса Ollama и изоляция через `ContextVar` |
| `image_io.py` | Чтение с учётом EXIF и прозрачности, запись по Unicode-путям, обрезка и подготовка изображений |
| `models.py` | Ленивая загрузка моделей, кэш весов в памяти, RT-DETRv2, вход и выход CTD |
| `ocr.py` | GLM-OCR через transformers, резервный вызов Ollama, очистка OCR и повторная попытка |
| `llm.py` | Запросы Ollama, кодирование изображений, проверка HTTP/API-ошибок и диагностический вывод |
| `page_analysis.py` | Анализ сцены, распознавание и сопоставление персонажей, определение говорящего |
| `translation.py` | Формирование запросов с контекстом и глоссарием, разбиение на пакеты, сопоставление ответов по ID |
| `context.py` | Архив персонажей, последние пять резюме с номерами страниц, журнал ошибок |
| `rendering.py` | Локальные маски текста, определение цвета и наклона, LaMa, перенос строк и отрисовка |
| `bubbles.py` | Единые поля бабла, совместимость со старыми заданиями, проверка правок редактора |
| `fonts.py` | Общий поиск каталогов и резервных шрифтов |
| `text_utils.py` | Очистка текста, извлечение JSON, естественная сортировка, признаки эмоциональной окраски |
| `storage.py` | Запись JSON через временный файл и атомарную замену |
| `web.py` | HTTP/WebSocket API, загрузка, выполнение заданий, редактор и экспорт |
| `web_ui.html` | Разметка интерфейса |
| `static/app.js`, `static/app.css` | Поведение и оформление интерфейса |
| `setup.py`, `run.bat`, `run.sh` | Подготовка окружения и запуск сервера |
| `tests/test_pipeline.py` | Регрессионные проверки без скачивания весов и обращения к Ollama |

## Поток обработки

Загрузка → чтение страницы → детекция → OCR → анализ сцены и говорящего → перевод → маска текста → удаление оригинала → отрисовка перевода → сохранение.

В быстром режиме анализ сцены и говорящего пропускается. Модели загружаются при первом использовании. Загрузчики защищены блокировкой; веб-задания и правки, использующие модели, выполняются последовательно, чтобы не конкурировать за GPU и архив персонажей. Запускайте сервер с одним worker: координация заданий находится внутри процесса.

## Представление данных

Бабл имеет одинаковые поля в обработчике, JSON API и редакторе: `x`, `y`, `width`, `height`, `text`, `translation`, `speaker`, `gender`, `text_color`, `text_angle` и параметры оформления. Цвет — RGB; преобразования в BGR происходят только на границе OpenCV. Результаты детектора ограничиваются границами изображения.

`source_box` появляется только после изменения геометрии. Он хранит исходную область текста для удаления и базовый размер для масштабирования; текущие `x/y/width/height` задают положение перевода. Поэтому перенос надписи не перемещает область удаления оригинала. Старые `w/h`, `_text_color`, `_text_angle`, `orig_w/orig_h` нормализуются при чтении. Для старых уже перемещённых баблов исходные координаты восстановить невозможно: прежний формат их не сохранял.

`_text_mask` — временная двумерная маска только обрезанной исходной области, а не всей страницы. Поля с начальным подчёркиванием не сохраняются в JSON. Для главы не накапливаются копии изображений и масок всех обработанных страниц. Результаты и конфигурация задания хранятся в `web_data/jobs`; `JOBS` содержит только состояние выполнения, очередь событий, задачу и сигнал отмены. Глоссарий читается в настройки при запуске операции, без второй глобальной копии.

Редактор отправляет правки, сервер проверяет их и возвращает обновлённые баблы. Повторного вычисления геометрии в JavaScript нет. Перерисовка, включая добавление найденных областей, начинается с исходной страницы, чтобы не накапливать артефакты очистки поверх предыдущего результата.

## Контракты моделей

| Модель | Вход | Обработка выхода |
| --- | --- | --- |
| RT-DETRv2 | RGB PIL; единственное масштабирование выполняет штатный processor, тензоры отправляются на устройство модели | `target_sizes` в порядке высота/ширина; координаты обрезаются по странице, пустые и неизвестные классы отбрасываются |
| GLM-OCR | RGB PIL напрямую из памяти; область предварительно ограничена страницей, длинная сторона вместе с полями не превышает 2048 px | Декодируются только новые токены; при ошибке локального запуска используется Ollama |
| CTD | RGB, contiguous NCHW, float32 `[0,1]`; размер из метаданных ONNX, пропорции сохранены, чёрные поля справа/снизу | Выбирается одноканальный выход сегментации, а не двухканальная карта детекции; поля удаляются в масштабе выхода, затем маска возвращается в размер страницы |
| LaMa | RGB NCHW `[0,1]` и бинарная маска N1HW `[0,1]`, размеры дополнены до кратных 8 | Дополнение удаляется; заменяются только замаскированные пиксели, проверяется форма результата |
| Ollama vision | Base64 PNG RGB, длинная сторона до 1024 px | HTTP/API-ошибки не выдаются за пустой успешный ответ; координаты в запросе относятся к явно указанному исходному размеру страницы |
| Ollama translation | JSON-пакеты с ID; контекст 8192 токена, до 2048 новых токенов | Ответ привязывается строго по целочисленному ID, дубли и неверные типы отправляются на повторную попытку |

Для перевода используется консервативный лимит размера UTF-8 входа с резервом под ответ и шаблон. Пакеты уменьшаются автоматически; если даже один элемент с контекстом не помещается, операция сообщает ошибку вместо скрытого обрезания. Это оценка, а не точный токенизатор произвольной Ollama-модели.

OCR-фрагменты сохраняются только при явно включённой отладке. Если LaMa недоступна или страница превышает лимит 12 миллионов пикселей, используется OpenCV inpaint. Ошибка перевода оставляет оригинал, вместо удаления текста ради надписи `[error]`.

Контракты сверены с [исходным кодом CTD](https://github.com/dmMaze/comic-text-detector/blob/master/inference.py), его [ONNX-обёрткой](https://github.com/dmMaze/comic-text-detector/blob/master/basemodel.py) и [примером GLM-OCR](https://huggingface.co/zai-org/GLM-OCR).

## Проверки

Обычный Python с установленными зависимостями:

```sh
python -m pip install -r requirements-dev.txt
python tests/run.py
ruff check .
ruff format --check .
node --check static/app.js
```

С готовым portable-окружением Windows: `python_embed\python.exe tests\run.py`.

Регрессионные тесты подменяют вызовы моделей и проверяют реальные преобразования изображений, геометрию, маски, JSON, изоляцию настроек и API. Дополнительно при рефакторинге выполнена проверка на кешированных RT-DETRv2, CTD, GLM-OCR и LaMa: страница `docs/sample_1_original.jpg` размером 1200×1660, 10 детекций, распознан китайский текст, получено изображение исходного размера. Полный перевод через живую Ollama-модель в эту проверку не входил.
